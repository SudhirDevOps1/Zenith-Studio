# ⚡ Skills Directory

> This folder contains reusable, battle-tested skills extracted from completed tasks.

## What is a Skill?
A Skill is a self-contained instruction file (`.md`) that tells any AI exactly how to perform a specific, repeatable task from zero context. It is created when a complex task is completed successfully (see `08_SKILL_CREATION.md` for the production format).

## How to Use a Skill
When starting a task, check if a skill exists for it:
1. Browse this directory for a relevant `.md` file.
2. If found → follow it exactly, it contains the full battle-tested workflow.
3. If not found → complete the task, then create a new Skill here.

## Naming Convention
`[category]_[action]_skill.md`

Examples:
- `auth_nextauth_setup_skill.md`
- `ui_glassmorphism_card_skill.md`
- `db_prisma_migration_skill.md`
- `deploy_vercel_nextjs_skill.md`
